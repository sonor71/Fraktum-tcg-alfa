# Temporary Pinterest reference extractions (prototype only)

The atlas `ref_items_atlas.png` is an exact pixel-cropped compilation of
12 small UI reference objects from the five images the project owner uploaded
on 2026-11-16. It is **not original art**, and its sources/owners have not
been verified. It is included for temporary UI evaluation on the prototype
deployment **only**, not as a freely licensed asset pack.

The tile layout is 6 columns x 2 rows at 32px each:
0: void book, 1: arcane book, 2: ice book, 3: green spellbook,
4: fire book, 5: bronze chest, 6: blue chest, 7: red chest,
8: purple chest, 9: folder icon, 10: mimic book, 11: data relic.

For commercial publication, contact the original artists or replace these
crops with independently authored, properly licensed pixel art. Pinterest
display alone is not permission to redistribute the content.
