# FRAKTUM — real pixel battle VFX (11 spritesheets)

These are pixel-art sprite sheets extracted from the user-supplied **PVFX Foundry 1.0.0**
archive, legacy/0.10.0. Frames were resized from 96×96 to 64×64 using
nearest-neighbor sampling and reduced to an indexed colour palette.

The original archive includes PVFX_FOUNDRY_LICENSE.txt, which explicitly
covers legacy/0.10.0 effect sprite sheets under **CC0 1.0 Universal**.
This applies to the sprite art, **not** to the effect-generation software,
toolkit source code, trademarks, or style documents.
